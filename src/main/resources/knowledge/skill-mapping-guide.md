> 核心原则：不是"推倒重来"，而是找到"技能最大公约数"。

## 技能迁移的"三步法"

**第一步：拆解**——把当前岗位拆成具体的能力模块，而不是笼统的"我在银行做柜员"。
例如：柜员 = 金融产品知识 + 客户沟通 + 合规意识 + 系统操作 + 现金管理。

**第二步：映射**——找出每个能力模块在新岗位中的对应价值。
例如：金融产品知识 → 产品运营（"我懂产品，现在教我用互联网方式推广它"）。

**第三步：补课**——只学"差的那一块"，而不是从零开始学一个全新领域。
例如：柜员转产品运营，只需补"互联网运营方法论"，不需要学编程或设计。

## 常见误区

1. **"我需要重新读个学位"** — 大多数转岗只需要 2-6 个月的针对性培训，不需要学位。
2. **"AI 时代我应该学编程"** — 不一定。编程是工具，不是目标。如果你的优势是人际沟通，客户成功经理比程序员更适合你。
3. **"转岗意味着降薪"** — 数据显示，成功的转岗（找到技能最大公约数的转岗）平均薪资增长 30-80%。关键是转对方向。
4. **"我年纪大了学不动了"** — 转岗不是"学新东西"，是"把旧东西用到新地方"。40 岁的银行柜员比 22 岁的应届生更懂金融产品，这是不可替代的优势。
