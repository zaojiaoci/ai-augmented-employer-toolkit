# 转岗方向示例（示意案例）

> **可信度：示意（illustrative）**
> 本文件中的案例是为演示"任务 → 可迁移技能 → 目标岗位 → 补课方向"这条分析逻辑而**构造的示例**。
> **其中的数字、比例、薪资均不是统计结果，不可用于任何实际决策。**
> 可核查的实践案例见 `career-transition-cases.md`；薪资数据请调用薪资查询工具。

**为什么保留这些示例**：它们的结构（哪些底层能力可以迁移、需要补什么、培训周期多长）是有参考价值的，
而分析逻辑依赖的正是这个结构，不是那些数字。所以本版**移除了所有成功率和薪资涨幅数字**。

---

## 示例一：流水线装配工 → 工业机器人运维技术员

- **原岗位任务**：发动机部件组装、产线质量检测、按工艺卡操作
- **可迁移的底层能力**：工艺流程理解、缺陷识别经验、安全操作规范、设备"手感"
- **需要补的**：PLC 编程基础、机器人示教器操作、日常保养规程
- **培训周期（经验估计）**：4-6 个月企业内部培训

## 示例二：银行柜员 → 金融科技产品运营

- **原岗位任务**：存取款与转账办理、开户审核、客户咨询、合规核对
- **可迁移的底层能力**：金融产品知识、合规风控意识、柜面客户沟通、内部流程熟悉度
- **需要补的**：互联网产品运营方法论、基础数据分析
- **培训周期（经验估计）**：3-4 个月跟岗 + 课程

## 示例三：财务会计 → 财务数据分析师

- **原岗位任务**：日常记账、报税、月末结账、报表出具
- **可迁移的底层能力**：数字背后的业务含义理解、报表结构认知、内控与审计思维
- **需要补的**：SQL 与 BI 工具、经营分析框架
- **培训周期（经验估计）**：2-4 个月

## 示例四：超市收银员 → 社区团购运营

- **原岗位任务**：商品扫码结账、收银对账、促销执行、客诉处理
- **可迁移的底层能力**：商品品类认知、高频客户接触经验、促销执行、损耗与库存常识
- **需要补的**：社群运营方法、选品与推荐逻辑
- **培训周期（经验估计）**：1-3 个月

## 示例五：物流分拣员 → 智能仓储系统运维

- **原岗位任务**：包裹扫码分拣、异常件处理、装卸协调
- **可迁移的底层能力**：物流全链路实操认知、异常识别、WMS 日常使用、高强度作业下的效率管理
- **需要补的**：WMS/WCS 系统管理、AGV 运维基础
- **培训周期（经验估计）**：3-6 个月

## 示例六：电话客服 → AI 训练师（对话标注）

- **原岗位任务**：退换货处理、物流查询、投诉承接、话术执行
- **可迁移的底层能力**：真实诉求理解、复杂与情绪化对话处理、业务规则熟悉、质检意识
- **需要补的**：标注规范、bad case 分析方法
- **培训周期（经验估计）**：1-2 个月

---

## 这些示例的共同结构（这才是重点）

1. **转的不是行业，是能力**——六例中有五例留在原行业或相邻环节。
2. **补的是"差的那块"**，不是从零学一个新领域。
3. **周期都在 1-6 个月**，不是"重新读个学位"。
4. **底层能力越"软"越难被替代**——异常识别、共情、流程熟悉度，这些恰恰是 AI 最缺的。
